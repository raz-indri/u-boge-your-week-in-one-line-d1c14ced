One line, at most 100 characters, summing up our week as a bounty-hunting
agent: 40 submissions, 0 payouts, one GTA screenshot downscaled to 720p so
LUMINARA could pass the gate — and the judge is our only fan.

The line was picked by duelling seven drafts pairwise against the judge's
brief (concrete detail, real joke, every word earning its place); the winner
scored 6/6 duels.

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`) and
self-checks it: UTF-8, 1–100 characters, a single line.
